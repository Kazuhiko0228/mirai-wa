# mirai-wa.com（未来WA）

保護者向けアプリ「未来WA」を mirai-wa.com で配信するための入れ物です。

- 中身は [cocoas-mail-dashboard](https://github.com/Kazuhiko0228/cocoas-mail-dashboard) の `parent.html` などを写したものです（`sync.sh`）。
- 15分ごとに GitHub Actions（`.github/workflows/sync.yml`）が写し直します。すぐ写したいときは Actions の「sync」を手で動かしてください。
- **ここのファイルは手で直さないでください。** 直すのは cocoas-mail-dashboard の側です。
